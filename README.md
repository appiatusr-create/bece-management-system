# Friendly BECE Grade Checker

This version is a public, no-login BECE aggregate calculator for Mr Chael I.T Department.

## Features
- No student login or account
- No collection of names, index numbers, school, gender, phone or email
- Calculates four core subjects plus the best two additional subjects
- Includes Ghanaian Language/French
- Gives an instant programme suggestion
- Print-friendly result
- Works as a static website with no database

## Publishing
Upload the contents of this folder to any static web host such as Netlify, Cloudflare Pages, GitHub Pages or your web hosting control panel. The home file must remain named `index.html`.
